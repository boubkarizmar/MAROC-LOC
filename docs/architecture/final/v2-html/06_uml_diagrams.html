Activité — Flux de Recommandation Collaborative filtering & Scoring

@startuml MAROC-LOC_Activity_Recommendation
start
:User loads homepage;
if (Authenticated?) then (yes)
    :Fetch user profile
    (favorites, views, searches);
    :Find similar users
    (Jaccard similarity);
    :Compute collaborative score;
else (no)
    :Fetch session behavior;
    :Build anonymous profile;
    :Use trending + geo + quality;
endif
:Get candidate properties (150 items);
:Batch fetch metrics (favorites, reviews, owners);
:Compute scores: Content(25%) Popularity(20%) Collaborative(25%) Recency(10%) Geo(10%) Trust(10%);
:Apply MMR diversity re-ranking;
:Cache result (Redis);
:Display recommendation cards;
:Track impressions;
stop

Activité — Flux Chatbot RAG Vector Search + Structured Search

@startuml MAROC-LOC_Activity_Chatbot
start
:User sends query;
:Detect language (fr/ar/en/darija);
:Translate to English (if needed);
:Classify intent (SEARCH/PRICE/EXPLORE/etc.);
:Extract entities (city, type, price, rooms);
fork
    :Vector Search (ChromaDB, top-k=10);
fork again
    :Structured Search (PostgreSQL);
end fork
:Merge & deduplicate results;
:Validate with PostgreSQL (check existence + availability);
if (Results found?) then (yes)
    :Generate response (FLAN-T5, multilingual);
    :Include property cards;
else (no)
    :Generate "not found" response;
    :Suggest alternatives;
endif
:Store conversation (Redis session);
:Display to user;
stop
