Dark Mode Strategy Auto-detect · Manual toggle · localStorage

Le toggle en haut à droite de cette page est fonctionnel. Essayez-le pour voir la bascule entre les deux thèmes en temps réel.

Theme Provider (React) TSX 
const ThemeProvider = () => {
  const [theme, setTheme] = useState(() => {
    const saved = localStorage.getItem('theme');
    if (saved) return saved;
    return window.matchMedia('(prefers-color-scheme: dark)').matches
      ? 'dark' : 'light';
  });

  useEffect(() => {
    document.documentElement.classList.toggle('dark', theme === 'dark');
    localStorage.setItem('theme', theme);
  }, [theme]);

  return <ThemeContext.Provider value={{ theme, setTheme }}>...</ThemeContext.Provider>;
};
