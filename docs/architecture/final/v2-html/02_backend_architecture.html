MAROC-LOC - Architecture Backend

Monolithe Modulaire Spring Boot 3.2.4 - Java 17/21 - Architecture en couches avec separation des modules metiers prete pour l'extraction microservices.

Paradigme : Monolithe Modulaire

MAROC-LOC adopte une architecture Monolithe Modulaire (Modular Monolith) plutot que des microservices distribues. Ce choix est justifie par :

  • Taille d'equipe : Equipe de developpement limitee (< 10 developpeurs)
  • Complexite operationnelle : Un seul deploiement a gerer
  • Transactions ACID : Besoin de coherence forte entre entites
  • Latence : Communication inter-modules en memoire (pas de reseau)
  • Evolutivite : Decoupage en modules prets pour future extraction en microservices
