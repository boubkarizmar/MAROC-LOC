MAROC-LOC — Système RAG et IA

Architecture hybride combinant retrieval sémantique, génération multilingue, mémoire conversationnelle et scoring avancé.

Vue d'ensemble
Architecture RAG Hybride

MAROC-LOC utilise une architecture RAG hybride combinant :

  • Retrieval sémantique — ChromaDB + embeddings MiniLM
  • Retrieval structuré — PostgreSQL avec filtres SQL
  • Génération multilingue — FLAN-T5 + NLLB-200
  • Mémoire conversationnelle — Redis (short-term) + PostgreSQL (long-term)

Scoring
Système de Scoring

Score de Qualité de Propriété

QualityScore =
  ListingCompleteness   × 0.15 +
  MediaQuality           × 0.15 +
  DescriptionQuality   × 0.10 +
  PriceCompetitiveness × 0.20 +
  EngagementVelocity   × 0.15 +
  TrustScore             × 0.10 +
  Freshness              × 0.10 +
  LocationPremium      × 0.05

Score Hybride de Recommandation

TotalScore =
  Collaborative × 0.25 +
  Content       × 0.25 +
  Popularity    × 0.20 +
  Recency       × 0.10 +
  Geo           × 0.10 +
  Trust         × 0.10 +
  Quality       × 0.10

Collaborative_decayed = Collaborative × exp(-days / 30)

MMR — Maximal Marginal Relevance

MMR_score = λ × relevance_score - (1-λ) × max_similarity_to_selected

λ = 0.75 (relevance vs diversity)
