MAROC-LOC — Architecture Système Globale

Plateforme PropTech fullstack dédiée au marché immobilier marocain avec intelligence artificielle avancée (RAG), chatbot multilingue et moteur de scoring dynamique.

Vue d'ensemble

MAROC-LOC est une plateforme PropTech (Property Technology) fullstack dédiée au marché immobilier marocain. Elle intègre une intelligence artificielle avancée (RAG) pour offrir :

  • Recommandations personnalisées basées sur le comportement utilisateur
  • Chatbot multilingue (français, arabe, darija) avec compréhension contextuelle
  • Moteur de scoring dynamique pour les propriétés et les utilisateurs
  • Recherche sémantique et géospatiale via PostGIS

Flux de Données End-to-End

1. Recherche de Propriété (with AI)

1
Utilisateur → Frontend
Query "appartement Casablanca 2 chambres"
2
Frontend → Backend
POST /v2/properties/search
3
Backend → PostgreSQL + AI Service
3a. PostgreSQL full-text search · 3b. Vector similarity search
4
AI Service → Models
4a. Intent classification (FLAN-T5) · 4b. Entity extraction (spaCy/Regex) · 4c. Vector search (ChromaDB)
5
AI Service → PostgreSQL
PG validation + re-ranking
6
Backend → Response
Merge + score + paginate
7
Frontend → UI
Render results + track impressions

2. Recommandation Personnalisée

1
Utilisateur → Frontend
Load homepage
2
Frontend → Backend
GET /recommendations/personalized
3
Backend → Data Sources
3a. Build user profile (PostgreSQL) · 3b. Find similar users · 3c. Compute property scores (In-memory)
4
Backend → Algorithm
Apply MMR diversity re-ranking
5
Backend → Redis
Cache result
6
Frontend → UI
Render cards + track impressions

3. Chatbot Conversation (RAG)

1
Utilisateur → Frontend
Voice/Text query "chrit dar f Marrakech"
2
Frontend → Backend
POST /ai/voice/chat OR /ai/rag/chat
3
Backend → AI Service
Forward to AI Service
4
AI Service → Models & DB
4a. Language detection (LangID) · 4b. Translate (NLLB-200) · 4c. Intent classification (BART-ZeroShot) · 4d. Vector search (top-k=10) · 4e. PG validation · 4f. Generate response (FLAN-T5)
5
AI Service → Backend
Multilingual response
6
Backend → Redis
Store conversation
7
Frontend → UI
Display response + property cards
